3. ENVIRONMENT SETUP (.env.local)
================================================================================

Step 1: In the project root folder, create a file called ".env.local"
Step 2: Copy the following content into .env.local:

  ┌─────────────────────────────────────────────────────────────────┐
  │                                                                 │
  │  # REQUIRED: Gemini AI API Key                                  │
  │  GEMINI_API_KEY=your_gemini_api_key_here                        │
  │                                                                 │
  │  # OPTIONAL: Supabase (for live analytics storage)              │
  │  NEXT_PUBLIC_SUPABASE_URL=your_supabase_url_here                │
  │  NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key_here      │
  │                                                                 │
  └─────────────────────────────────────────────────────────────────┘

IMPORTANT:
  - .env.local is already in .gitignore — it will NOT be committed
  - The app works WITHOUT Supabase (Module 4 uses sample data)
  - You MUST set GEMINI_API_KEY for Modules 1 and 2 to work

4. GETTING A GEMINI API KEY (REQUIRED)
================================================================================

This is the ONLY required setup step.

  1. Go to: https://aistudio.google.com/apikey
  2. Sign in with your Google account
  3. Click "Create API Key"
  4. Select "Create API key in new project" (or pick an existing one)
  5. Copy the generated API key
  6. Paste it into your .env.local file:

       GEMINI_API_KEY=AIzaSyB-your-actual-key-here

  ⚠️ The free tier gives you 15 requests per minute — plenty for demos!
  ⚠️ NEVER share this key publicly or commit it to Git

5. SETTING UP SUPABASE (OPTIONAL)
================================================================================

Supabase is ONLY needed if you want live data storage for Module 4.
The app works perfectly WITHOUT it (uses built-in sample analytics data).

If you DO want to set it up:

  STEP A — Create a Supabase Project
  ────────────────────────────────────
  1. Go to: https://supabase.com
  2. Sign up / Log in
  3. Click "New Project"
  4. Pick a name (e.g., "nexttalent"), set a password, pick a region
  5. Wait for the project to be created

  STEP B — Get Your Keys
  ────────────────────────
  1. In your project dashboard, go to: Settings → API
  2. Copy the "Project URL" → paste as NEXT_PUBLIC_SUPABASE_URL
  3. Copy the "anon public" key → paste as NEXT_PUBLIC_SUPABASE_ANON_KEY

  STEP C — Create Database Tables
  ─────────────────────────────────
  Go to SQL Editor in Supabase and run this SQL:

  ┌─────────────────────────────────────────────────────────────────┐
  │                                                                 │
  │  -- Table for voice roadmap sessions                            │
  │  CREATE TABLE roadmap_sessions (                                │
  │    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,               │
  │    transcript TEXT NOT NULL,                                    │
  │    career_title TEXT NOT NULL,                                  │
  │    required_skills TEXT[] DEFAULT '{}',                         │
  │    steps_count INTEGER DEFAULT 0,                               │
  │    created_at TIMESTAMPTZ DEFAULT NOW()                         │
  │  );                                                             │
  │                                                                 │
  │  -- Table for skill analysis results                            │
  │  CREATE TABLE skill_analyses (                                  │
  │    id UUID DEFAULT gen_random_uuid() PRIMARY KEY,               │
  │    career_title TEXT NOT NULL,                                  │
  │    match_percentage INTEGER DEFAULT 0,                          │
  │    matched_skills_count INTEGER DEFAULT 0,                      │
  │    missing_skills TEXT[] DEFAULT '{}',                           │
  │    created_at TIMESTAMPTZ DEFAULT NOW()                         │
  │  );                                                             │
  │                                                                 │
  │  -- Enable Row Level Security (recommended)                     │
  │  ALTER TABLE roadmap_sessions ENABLE ROW LEVEL SECURITY;        │
  │  ALTER TABLE skill_analyses ENABLE ROW LEVEL SECURITY;          │
  │                                                                 │
  │  -- Allow inserts from anon (for demo purposes)                 │
  │  CREATE POLICY "Allow inserts" ON roadmap_sessions              │
  │    FOR INSERT WITH CHECK (true);                                │
  │  CREATE POLICY "Allow selects" ON roadmap_sessions              │
  │    FOR SELECT USING (true);                                     │
  │                                                                 │
  │  CREATE POLICY "Allow inserts" ON skill_analyses                │
  │    FOR INSERT WITH CHECK (true);                                │
  │  CREATE POLICY "Allow selects" ON skill_analyses                │
  │    FOR SELECT USING (true);                                     │
  │                                                                 │
  └─────────────────────────────────────────────────────────────────┘

  STEP D — Enable Google OAuth (OPTIONAL — for "Sign in with Google")
  ────────────────────────────────────────────────────────────────────
  If you want the "Sign in with Google" button to work, follow these steps:

  1. Create a Google OAuth Client:
     a. Go to: https://console.cloud.google.com/apis/credentials
     b. Create a new project (or select your existing one)
     c. Click "Create Credentials" → "OAuth client ID"
     d. Application type: "Web application"
     e. Name: "NextTalent"
     f. Authorized redirect URIs — add BOTH of these:
          http://localhost:3000/auth/callback          (for local dev)
          https://YOUR-PROJECT-REF.supabase.co/auth/v1/callback
        (Replace YOUR-PROJECT-REF with your Supabase project reference ID.
         You can find it in: Supabase Dashboard → Settings → API → URL)
     g. Click "Create" and copy the Client ID and Client Secret

  2. Configure Google Provider in Supabase:
     a. Go to your Supabase Dashboard → Authentication → Providers
     b. Find "Google" in the list and click to expand
     c. Toggle "Enable Sign in with Google" to ON
     d. Paste your Google Client ID
     d. Paste your Google Client Secret
     f. Click "Save"

  3. Configure OAuth Consent Screen (if prompted):
     a. In Google Cloud Console → APIs & Services → OAuth consent screen
     b. User type: "External"
     c. Fill in app name: "NextTalent"
     d. Fill in support email (your email)
     e. Add scopes: email, profile, openid
     f. Add test users (your email) if in "Testing" mode
     g. Click "Save and Continue"

  ⚡ That's it! The "Sign in with Google" button on /auth will now work.
  ⚠️ For production, publish the OAuth consent screen to avoid test-user
     restrictions.

6. RUNNING THE APP LOCALLY
================================================================================

  Step 1: Open a terminal in the project folder
  Step 2: Install dependencies (if not already done):

       > npm install

  Step 3: Start the development server:

       > npm run dev

  Step 4: Open your browser and go to:

       http://localhost:3000

  That's it! The app should be running.

  PAGES YOU CAN VISIT:
  ─────────────────────
    http://localhost:3000                 ← Landing Page

7. DEPLOYING TO VERCEL (FOR LIVE DEMO URL)
================================================================================

  Step 1: Push your code to GitHub
  ─────────────────────────────────
    > git init
    > git add .
    > git commit -m "Initial commit: NextTalent"
    > git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
    > git push -u origin main

  Step 2: Deploy to Vercel
  ─────────────────────────
    1. Go to: https://vercel.com
    2. Sign up with GitHub
    3. Click "Import Project" → Select your repo
    4. In the "Environment Variables" section, add:
         GEMINI_API_KEY = your_key_here
         NEXT_PUBLIC_SUPABASE_URL = your_url (if using Supabase)
         NEXT_PUBLIC_SUPABASE_ANON_KEY = your_key (if using Supabase)
    5. Click "Deploy"
    6. Your live URL will be: https://your-project-name.vercel.app

  ⚡ Vercel automatically rebuilds when you push to GitHub!

8. HOW THE 4 MODULES WORK
================================================================================

  MODULE 1: Voice-to-Roadmap AI Assistant
  ────────────────────────────────────────
  • User clicks microphone → speaks their dream career
  • Browser's Web Speech API converts speech to text
  • Text is sent to POST /api/generate-roadmap
  • Gemini AI generates a structured JSON career roadmap
  • Frontend renders it as a beautiful vertical timeline
  • Data is stored in Supabase (if connected)

  MODULE 2: Automated Skill-Gap Analyzer
  ───────────────────────────────────────
  • User pastes their resume/bio text
  • Resume + Roadmap data sent to POST /api/analyze-skills
  • Gemini AI compares current skills vs. required skills
  • Returns match percentage, matched skills, missing skills
  • Displayed as progress bar + two-column skills grid

  MODULE 3: Micro-Learning Recommender
  ────────────────────────────────────
  • Takes missing skills from Module 2
  • Sends to POST /api/recommend-courses
  • Matches against local database of 25 curated courses
  • Returns 2-3 free courses per missing skill
  • Links directly to Coursera, Udemy, edX, etc.

  MODULE 4: Workforce Analytics Dashboard
  ───────────────────────────────────────
  • Fetches aggregated data from GET /api/analytics
  • Displays 4 KPI cards (sessions, analyses, match%, universities)
  • 4 Chart.js charts (careers bar, match donut, skills bar, university bar)
  • Weekly trend table + policy insight cards
  • Works with sample data OR live Supabase data

9. TROUBLESHOOTING
================================================================================

  PROBLEM: "Microphone not working"
  → Make sure you're using Chrome or Edge
  → Check browser permissions (click lock icon in address bar)
  → HTTPS is required in production (Vercel handles this)

  PROBLEM: "Failed to generate roadmap"
  → Check that GEMINI_API_KEY is set in .env.local
  → Restart the dev server after changing .env.local
  → Check the terminal for error messages

  PROBLEM: "Charts not loading on dashboard"
  → Hard refresh the page (Ctrl+Shift+R)
  → The charts use dynamic imports — may take a moment

  PROBLEM: "Module 2 says no roadmap loaded"
  → Go through Module 1 first and click "Analyze My Skills"
  → This passes the roadmap data via URL query params

  PROBLEM: "npm install fails"
  → Delete node_modules and package-lock.json
  → Run: npm install
  → Make sure Node.js is v18+

  PROBLEM: "Supabase not connecting"
  → The app works WITHOUT Supabase — it's optional
  → Check that URLs and keys are correct in .env.local
  → Make sure the tables exist (see Section 5)
