# NextTalent

> **Voice-Activated Future Talent Ecosystem**

NextTalent is a state-of-the-art career guidance and workforce analytics platform. Using the browser-native **Web Speech API**, **Google Gemini 2.5 Flash**, **TypeScript**, and **Supabase**, it provides a seamless 4-module pipeline that guides students from voice career exploration to skill analysis, learning, and policymaker analytics.

---

## 🚀 Key Features (The 4 Core Ecosystem Sections)

1. **🎤 Voice-to-Roadmap AI Assistant**
   * Convert spoken career goals/interests (via browser Web Speech API) into detailed, structured, step-by-step career roadmaps generated by **Gemini 2.5 Flash**.
   * Renders as an interactive visual timeline showing steps, durations, and skill requirements.

2. **📊 Automated Skill-Gap Analyzer**
   * Paste your resume/biography to compare your current skill set against the generated career roadmap requirements.
   * Employs Gemini to calculate an overall match percentage and classify matched vs. missing skills with evidence and recommendations.

3. **📚 Micro-Learning Recommender**
   * Directly extracts the missing skills identified in the Skill-Gap Analyzer.
   * Recommends free, highly rated courses (from a curated local database of 25 courses across major domains) with direct links.

4. **📈 Workforce Analytics Dashboard**
   * Aggregates platform-wide session logs and skill gap statistics.
   * Powered by dynamic **Chart.js** visualizations showing search trends, national skill gap counts, match distributions, and university breakdown analysis.

---

## 🛠️ Tech Stack & Architecture

* **Framework:** Next.js 15 (App Router)
* **Language:** TypeScript (Strict Mode)
* **AI Engine:** Google Gemini 2.5 Flash (via `@google/genai` SDK)
* **Database & Persistence:** Supabase (optional, falls back gracefully to mock database for local preview)
* **Charts:** Chart.js + react-chartjs-2
* **Styling:** Vanilla CSS Modules with custom variables/glassmorphism design tokens

## 📦 Setup & Installation

### 1. Prerequisites
Ensure you have **Node.js v18+** and **npm** installed.

### 2. Install Dependencies
```bash
git clone <repository-url>
cd nexttalent
npm install
```

### 3. Configure Environment variables
Create a `.env.local` file in the root folder (see `.env.example`):
```env
# REQUIRED: Get yours from https://aistudio.google.com/apikey
GEMINI_API_KEY=your_gemini_api_key_here

# OPTIONAL: Get yours from https://supabase.com
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 4. Run the App
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.
